Add a way to register a name for a custom log level, both globally and locally per-logger, so it can be written and read back as text the same way the built-in levels already are.

This local registry overrides the global registry for that logger's text form (JSON/Console output). Parsing the name back (case-insensitively) must produce the original level via `zerolog.ParseLevel` (global) or `ConsoleWriter` (local registry attached).

Registering an empty name should be rejected. This all needs to work correctly when used concurrently from multiple goroutines.

Add `Snapshot` for an independent registry copy, so a sink's view does not shift when the original gets a new registration elsewhere. Add atomic `LoadLevelRegistry` validation: an invalid batch commits nothing and reports its validation failures instead of building a partial registry. Add `Conflicts` to report names that have drifted into collision with a built-in's current marshal output, without modifying the registry, since `LevelFieldMarshalFunc` is mutable. Add `Merge` to combine two registries into a new, independent one without modifying either input: a level present in both is only a conflict if the two sides disagree on its name, and any case-insensitive collision across the combined entries is also a conflict, committing nothing either way. `Merge` must never deadlock when two registries are merged from both directions concurrently, regardless of call order.

The public API must be exactly: constructor `NewLevelRegistry() *zerolog.LevelRegistry`; global functions `RegisterLevel(level Level, name string) error` and `UnregisterLevel(level Level)`; matching `*LevelRegistry` methods `RegisterLevel(level Level, name string) error` and `UnregisterLevel(level Level)`; `func (r *LevelRegistry) Snapshot() *LevelRegistry`; `func LoadLevelRegistry(entries map[Level]string) (*LevelRegistry, error)`; `func (r *LevelRegistry) Conflicts() []error`; `func (r *LevelRegistry) Merge(other *LevelRegistry) (*LevelRegistry, error)`; a `Logger` method `func (l zerolog.Logger) LevelRegistry(*zerolog.LevelRegistry) zerolog.Logger` to attach a scoped registry to that logger's output; and a public `ConsoleWriter` field `LevelRegistry *zerolog.LevelRegistry`, used by its level formatter and ParseLevel path.

`Level.String()` and `ParseLevel` read only the global registry; a scoped registry attached to a logger or ConsoleWriter affects only that sink, never `Level.String()` itself. Both registries must be safe for concurrent use.

Both global and local `RegisterLevel` calls reject empty names; reject any name that collides with a built-in name, including the `warning` alias; refuse to rename a built-in level, including `NoLevel` and `Disabled`; reject a name that collides case-insensitively with the name already registered by a different custom level in the same registry; and validate collisions against the exact output of `LevelFieldMarshalFunc` at the time of registration, using case-insensitive `strings.EqualFold` semantics throughout. Re-registering an existing custom level replaces its old name, unregistering restores the numeric string representation, and unregistering a level that was never registered is a no-op.
