# AfterQuery Gold Maintainer

[Back to portfolio](../../README.md)

AfterQuery Gold Maintainer work turns repository changes into software-agent evaluation tasks. A task needs an understandable engineering request, a valid implementation, an executable grading strategy, and evidence that the grader distinguishes correct work from incomplete or incorrect changes.

I contribute as both a **task author** and a **maintainer reviewer**.

## Verified outcomes

As checked in the author dashboard on **November 19, 2026**:

- **87 completed reviews** of maintainer tasks.
- **4 approved authored tasks**: `one-file-build`, `yard-writes-one-commit`, `one-seat-per-week`, and `submitted-links-web-only`.

The review total measures completed review work, not unique repositories or accepted tasks. The approved total excludes failed submissions and locally prepared bundles.

## Task authoring

My authoring work includes investigating existing behavior, identifying a scoped change, implementing a reference solution, preparing an alternative valid approach and a negative control, and designing behavioral grading criteria. I also work on environment setup, compatibility checks, failure cases, and iteration after validation feedback.

The [approved case studies](approved-tasks.md) cover Python packaging and transactional CLI behavior alongside TypeScript reservation and URL-validation work. The [task catalogue](task-catalog.md) records unsuccessful and unfinished work separately.

## Maintainer review

Reviewing requires reading the engineering request, implementation and tests together, then checking current pipeline evidence and model attempts. A green automated badge alone does not establish that a task is fair, correct, or mergeable.

I examine whether requirements are discoverable, tests measure the requested behavior, valid alternatives remain possible, and failures actually result from the task rather than a broken environment. I record uncertainty explicitly when logs are missing or reports conflict.

See [review experience](review-experience.md) for the practical skills developed across this work.
